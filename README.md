# Mehrdad Seif — Next.js Portfolio

A responsive dark premium portfolio inspired by the approved UI direction: Apple/iOS-style glass surfaces, blue + emerald accents, large Arial typography, subtle glow, hover motion and RTL-ready structure.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize
- Replace the hero placeholder in `app/page.tsx` with the real portrait.
- Replace `/public/design-reference.png` with project-specific images.
- Edit project/service data at the top of `app/page.tsx`.
- Main styling is in `app/globals.css`.
